Ranking is the task of ordering the documents that match a query so that the
most relevant ones appear first. The classic vector space model scores a
document by the cosine similarity between the query vector and the document
vector, using tf-idf weights.

Modern search engines, including Apache Lucene, use BM25 as the default ranking
function. BM25 is a probabilistic model that rewards term frequency with
diminishing returns and penalizes long documents through length normalization.

Evaluation of ranking quality uses metrics such as precision, recall, mean
average precision and normalized discounted cumulative gain.
