In Lucene an Analyzer turns raw text into the terms that are actually stored in
the index. A typical analysis pipeline is a Tokenizer followed by one or more
TokenFilters.

The StandardAnalyzer splits text on word boundaries, lowercases every token and
removes a small set of English stop words. The EnglishAnalyzer additionally
applies a stemming filter so that "searching", "searched" and "searches" all
reduce to the same stem.

The same Analyzer should be used both when indexing a document and when parsing
a user query, otherwise the terms will not match.
